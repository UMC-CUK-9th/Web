## ✨ 프로젝트 개요

본 프로젝트는 **Make:us 웹 개발 챌린지**를 통해  
React 생태계와 Modern JavaScript 기술 스택을 깊이 있게 학습하고  
**실무 수준의 사용자 경험(UX) 및 성능 최적화 역량 강화를 목표**로 진행되었습니다.  
실제 프로젝트 환경을 기반으로 주요 기능들을 설계·구현했습니다.

---

## 🚀 주요 학습 내용 및 구현 기능

---

# 🧩 **Chapter 01 ~ 02: 핵심 JavaScript & React 기본 (TypeScript 기반)**

### 📘 학습 내용 & 주요 성과

### ✔ **TypeScript 도입**
- 프로젝트 전체에 TS 적용  
- 데이터 구조 안정성 확보  
- 컴파일 단계에서 오류를 조기 발견하여 유지보수성 향상  

### ✔ **React 기본기**
- useState, useEffect, useCallback, useMemo 활용  
- 렌더링 최적화 및 의존성 관리 능력 습득  

### ✔ **전역 상태 관리**
- Context API + useReducer 적용  
- 사용자 인증/로그인 상태 등 전역 상태를 구조적으로 관리  

### ✔ **기본 데이터 구조 설계**
- Todo 리스트 등 컴포넌트 기반 데이터 모델링 연습  
- 상태 변화 흐름을 설계하며 컴포넌트 구조 확립  

---

# 🎨 **Chapter 03 ~ 04: API 통신, 스타일링, 라우팅**

### 📘 학습 내용 & 주요 성과

### ✔ **Tailwind CSS 적용**
- Utility-first 디자인  
- 반응형 UI 구축  
- 빠르고 일관된 스타일링 작업 가능  

### ✔ **React Router v6**
- SPA 라우팅 구조 설계  
- 동적 경로 및 페이지 전환 구현  

### ✔ **API 통신 기초 (fetch / axios)**
- CRUD 패턴 학습  
- try/catch 기반 오류 처리 로직 구현  

### ✔ **영화 검색·목록 기능 구현**
- 외부 API 연동  
- 검색, 목록 렌더링, 로딩/에러 상태 처리 경험  

---

# ⚡ **Chapter 05 ~ 09: 고급 상태 관리 및 성능 최적화**

### 📘 학습 내용 & 주요 성과

### ✔ **TanStack Query (React Query)**
- 서버 상태 관리(Server State) 전문 도구 도입  
- 캐싱 / 자동 리페칭 / 로딩 & 에러 상태 관리 자동화  
- useInfiniteQuery 기반 데이터 무한 로딩  

### ✔ **무한 스크롤 (Infinite Scroll)**
- Intersection Observer or Throttle 기반 스크롤 감지  
- 대용량 데이터 UX 개선  

### ✔ **성능 최적화 – Debounce**
- useDebounce 커스텀 훅 구현  
- 검색 입력 시 불필요한 API 호출 방지  

### ✔ **성능 최적화 – Throttle**
- useThrottle 커스텀 훅 구현  
- 스크롤·리사이즈 등 고빈도 이벤트 제어  

### ✔ **사용자 경험(UX) 개선**
- Sidebar ESC 키 닫기  
- 오버레이 열림 시 body scroll lock 적용  
- 자연스럽고 직관적인 UI 동작 구현
